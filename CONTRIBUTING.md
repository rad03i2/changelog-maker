# Contributing / المساهمة

Contributions are welcome when they keep the tool focused, deterministic, and safe. Fork the repository, create a focused branch, add or update tests, run `pytest`, and open a pull request describing behavior changes. Use Conventional Commits when practical. Do not commit generated environments, credentials, tokens, or private repository data.

نرحب بالمساهمات التي تحافظ على بساطة الأداة وقابليتها للتوقع وأمانها. أنشئ فرعًا محدد الهدف، أضف أو حدّث الاختبارات، شغّل `pytest`، ثم افتح Pull Request يشرح تغيير السلوك. لا ترفع أسرارًا أو رموز وصول أو بيانات مستودعات خاصة.
